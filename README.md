# Nail Master Dallas — Fox Nails layout concept

A separate, one-page Next.js concept for Nail Master Dallas. The section order and storefront layout take inspiration from Fox Nails USA, while the logo, color palette, product imagery, copy, and links use Nail Master Dallas content.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

The product and collection actions link to the existing Nail Master Dallas Shopify site. This is a frontend mockup for review, not a connected checkout or Shopify theme. The previous Nail Master Dallas concept lives in its separate project and is unchanged.
